\## Как пользоваться справочником



Для изучения материала рекомендуется следующий порядок:



1\. Прочитать README.md и ознакомиться с целью проекта.

2\. Изучить основные понятия в glossary.md.

3\. Разобрать практические примеры в examples.md.

4\. Изучить использованные источники в sources.md.

5\. Ответить на вопросы для самопроверки в questions.md.



Материал следует изучать последовательно,

выполняя примеры самостоятельно.
